### Sunflower
Sunflower is a cross-platform screen time limiter tool. It tracks the time spent in specific apps and once the allowance is exceeded, minimizes them.

### Build locally
Clone the repository:
```
git clone https://github.com/bergamontt/sunflower.git
cd sunflower
```
Create build folder:
```
mkdir build
cd build
```
Build with CMake:
```
cmake ..
cmake --build .
```
To run the tests:
```
./tests/tests
```
